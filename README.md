# 📝 To-Do List

A simple and clean **To-Do List** web application built with **HTML, CSS, and JavaScript**.

## ✨ Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* 🔍 Search tasks in real time
* 🚫 Prevent duplicate tasks
* ⚠️ Prevent adding empty tasks
* 📭 Show a message when the list is empty
* 📱 Simple and responsive-friendly design

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
To-Do-List/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding your tasks!

## 🔎 How It Works

### Add a Task

Type a task in the input field and click the **Add** button.

### Delete a Task

Click the **Delete** button next to a task.

### Search

Use the search box at the bottom to find tasks instantly.

### Duplicate Protection

The application checks existing tasks and prevents adding the same task twice.
